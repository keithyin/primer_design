### 术语约定（复核者必读，避免三处常见误解）

**(1) "GCC-family"（GCC 家族）不是一个字面序列。** 它指三核苷酸 GC-rich 重复家族，
六种 phase/strand 表示互为同一条重复：`GCC`/`CCG`/`CGC`（正链三相位）与
`GGC`/`CGG`/`GCG`（互补链三相位）。**并不要求序列必须字面重复 `GCC`。**
因此表 A/C 中各行的单元可能写作 `CGG`（FMR1）、`CCG`（AFF2、HMGB3）、`GGC`（CARM1）、
`CGC`（FAM193B）、`GCC`（GIGYF1、chr12）——它们属于同一家族。

**(2) 3' 端 15-mer 的两个计数，定义如下**（这是本报告最容易被误读的一处）：

| 字段 | 定义 |
|---|---|
| `3'15mer 总命中` | 该引物 **3' 端 15-mer 及其反向互补** 在全基因组双链中的**精确**出现次数（按位置计数，含重叠） |
| `3'15mer 异地命中` | `总命中 − 该引物所在染色体上的命中数`。**即"跨染色体"命中，不是"除目标位点外的全部命中"** |

由此可直接推出表 B 的关系：`pair 异地命中 = F 异地 + R 异地`，
且**总命中 ≠ 异地命中**（差额是该引物所在染色体上的命中，其中包含目标位点本身）。

> **⚠️ 该定义的一个重要后果（本版新增披露）**：同一染色体上的**非目标**命中会被计入"总命中"
> 却**不计入**"异地命中"。也就是说，异地命中数**系统性偏低**。
> 24 行中有 14 条引物存在这种情况，最极端的例子是 **#6 HMGB3 的正向引物**：
> 总命中 2、异地命中 **0**——即在 chrX 上除目标位点外还有 1 处命中，却在表中显示为"0"。
> 若要"全部非目标命中"的近似值，应取 `总命中 − 1`（目标位点贡献至少 1 次），
> 而非 `异地命中`。本报告的表 B 保留原始定义值，并在此声明其偏低的方向与幅度。

**(3) 重复单元数的两套口径**（详见 §9.5）：(GC)n 行用"**最大完美串联**"定义，
GCC-family 行用 **walk 定义**（允许吸收 ≤2 个连续非精确单元）。两套口径的边界不同，
**不能互相比较**。例如 FMR1 按 walk 记账为 22 单元，按经典生物学定义（CGG 重复）核心为约 20 单元。

### `flag` 列语义（复核者最易误读的一列）

`ok` = 全长异地匹配 0 且 3' 15-mer 异地命中 ≤ 10；
`ok_check` = 全长异地匹配 0 但 3' 15-mer 异地命中 > 10，即**"需要人工看一眼"**，并非"设计失败"。
全部 24 行的全长命中均为 1（即无第二处精确匹配，该结论不受 §1 定义问题影响）。
判据字段的完整定义见 §1 术语约定 (2)。

> **⚠️ 本版新披露的判据问题**：`flag` 的阈值建在"**异地命中**"上，而该字段按 §1 术语约定 (2)
> **系统性偏低**——它不计入同染色体上的非目标命中。按修正口径（`总命中 − 2`）重算，
> **#21 ENSG00000237761 为 11 > 10，会越界翻成 `ok_check`**，因此"18 ok + 6 ok_check"
> 这个分界是口径的产物而非自然断点。
> **本版未改判据**（改则需重算并重出全部交付行，且会与 `method_D_genomescan.json` 的既有字段脱钩）。
> 复核者若需要更保守的筛查，请直接用 `method_D_genomescan.json` 的逐侧 `end15_hits`，
> 取 `总命中 − 2` 作为非目标命中的近似值（§6.3、§12.8 已按此口径给出重排表）。

## 3. 关键事实：参考基因组中 GC 重复的真实分布

参考装配是**单一单倍型**，患者型长等位（(CGG)>55、(GGC)>45 等）不存在于参考序列中。
常用的 TRF / simpleRepeat 轨道因打分阈值会漏掉短的 GC 重复，因此本项目**直接做序列级串联扫描**。

因"含中断"重复的边界对种子阈值存在 ±1–2 单元的定义敏感性，下表并列三种种子阈值的稳健结果：

| 家族 | 完美串联最长 | 含中断（单元计）最长 | ≥20 拷贝位点数 | ≥30 拷贝位点数 |
|---|---|---|---|---|
| (GC)n 二核苷酸 | **14 拷贝**（chr19:47,271,733） | **18**（chrX:2,574,014 区） | **0**（12 bp 种子下仍为 0） | **0** |
| (GCC)n 家族（6 种阅读框/相位，含正反链） | **23 拷贝**（chr7 GIGYF1 的 (CCG) 完美段） | 常规种子（≥10 单元纯核）25；密扫种子（≥8 单元）**32** | 常规 6；密扫 **10** | 常规 0；密扫 **1** |

**由此产生的设计决策**：`>30` 档由密扫（≥8 单元种子）新发现的 chr12:7,628,695 位点填补
（该位点结构已由 UCSC 独立核验，§10.1）；FMR1 与 AFF2 两行标注为"扩展检测"。

**扩增容量的正确表述**（本版已更正原报告与 README 的过度表述）：

| 位点 | GRCh38 参考序列重复单元数 | 非重复骨架 | 1 kb 产物理论上限 | 覆盖 200 拷贝所需产物 |
|---|---|---|---|---|
| FMR1 | 22 | 657 bp | **~114 拷贝** | ~1.26 kb |
| AFF2 | 21 | 719 bp | **~93 拷贝** | ~1.32 kb |

计算式：`上限拷贝数 = floor((产物上限 − 非重复骨架) / 单元长)`，非重复骨架 = `产物长度 − tract 长度`。
**结论**：1 kb 产物只能覆盖 FMR1 前突变区间（55–200）的**下段（55–114）**，
AFF2 更无法触及 >200 的扩增区间；**原报告"覆盖前突变范围"的表述是错的**。
若要覆盖 200 拷贝，产物上限需放宽到 ~1.26 / ~1.32 kb——**远在 2 kb 硬上限之内**，是可行的设计调整。
（放宽到 2 kb 的理论上限约 ~447 / ~427 拷贝，但长 GC 产物的扩增效率需实验验证。）

> **⚠️ 证据可得性警告**：本节分布表全部数字来自 `data/` 目录下的扫描文件
> （`genome_scan.tsv`、`interrupted_scan.tsv`、`dense_scan.tsv`、`repeat_extremes.json`、
> `sensitivity_15bp.json`、`sensitivity_dinuc.json`），而 `data/` 已被 `.gitignore` 排除，
> **不在交付包内**。外部复核者目前**无法从仓库重算本节任何一个数字**。
> 严格地说，"参考基因组中不存在 ≥20 拷贝的 (GC)n"是一个**全基因组负结论**，
> 在缺少 fasta + 扫描程序 + 参数 + 结果的情况下只能算"报告值"，**不能算已证**。
> 唯一的例外是 chr12 `>30` 位点——那是一个**正结论**，已由 UCSC 独立核验（§10.1）。

## 4. 方法（依据 `scripts/` 源码逐条核对）

### 4.1 位点发现

序列级扫描（正反链、全部阅读框），纯 GC 核种子 + 严格外推：

- 种子：`[GC]{30,}`（常规，≥10 单元）、`[GC]{24,}`（密扫，≥8 单元）、`[GC]{15,}`（敏感性，≥5 单元）；
- 外推（walk）规则：允许**最多 2 个连续非精确单元**（`max_streak=2`），且走过 ≥4 个单元后要求运行精确率 ≥ 0.6（`min_purity=0.6`）；
- 过滤：`purity ≥ 0.75`、`n_units ≥ 16`；
- 硬性不变量（全部扫描输出均加断言）：`tract 长度 == 单元数 × 单元长`；
- 二核苷酸行采用**"最大完美串联"**定义（两侧不可再延伸），与三核苷酸的 walk 定义不同（见 §9.4）；
- 面板组装：`09_build_panel.py` 从 `interrupted_scan.tsv` + `dense_scan.tsv` 取 14 个 GCC 位点（含强制注入的 FMR1/AFF2/HMGB3/TMEM185A 与 chr12 密扫行），另**硬编码** 10 个 (GC)n 位点，合计 24。

### 4.2 引物设计（primer3-py 2.3.1）

| 参数 | 值 |
|---|---|
| 长度 | `PRIMER_MIN_SIZE 20` / `OPT_SIZE 22` / `MAX_SIZE 28` |
| Tm | `MIN_TM 57.0` / `OPT_TM 60.0` / `MAX_TM 64.0` |
| GC% | `MIN_GC 35.0` / `OPT_GC 50.0` / `MAX_GC 65.0` |
| 盐与浓度 | `SALT_MONOVALENT 50.0` mM / `SALT_DIVALENT 1.5` mM / `DNA_CONC 50.0` nM / dNTP 0.6 mM |
| 二聚体/发夹（**`_TH` 族**） | `MAX_SELF_ANY_TH 47.0` / `MAX_SELF_END_TH 47.0` / `MAX_HAIRPIN_TH 47.0`；配对级 `PAIR_MAX_COMPL_ANY_TH 47.0` / `_COMPL_END_TH 47.0`（见 §9.22） |
| 3' 端稳定性 | `MAX_END_STABILITY 6.0`（primer3 默认 100，此项为实收紧） |
| 其他 | `MAX_POLY_X 5`（等同默认）、`NUM_RETURN 10`、不选内部寡核苷酸 |

> **`_TH` 族不可省略**（§9.22）：primer3-py 默认开启 thermodynamic oligo alignment，此时
> `PRIMER_MAX_SELF_ANY` / `_SELF_END` 这类**非 `_TH` 键不参与判定**；`PRIMER_MAX_HAIRPIN`
> 更是一个**不存在的键名**（只有 `PRIMER_MAX_HAIRPIN_TH`），而 primer3-py 对未知键**静默忽略**。

- 约束区间：`SEQUENCE_TARGET` 与 `SEQUENCE_EXCLUDED_REGION` **设为同一区间**（= 重复 tract ± 3 bp），即"扩增子必须夹住重复"且"引物不得落在重复内"；
- `widen_exclusion()` 会把该区间沿相邻的周期-2 简单重复（CA/TG/GC 等）自动外扩，避免引物落入旁邻微卫星；
- 退火温度回退：常规优先 `[[250,900]]`，逐级放宽到 `[[200,1000]]→[[200,1600]]→[[200,2000]]`；扩展检测行（FMR1/AFF2）走另一条更紧的阶梯；
- 富 GC 模板失败时二次尝试放宽：`MAX_GC 75.0`、`MIN_GC 30.0`、`MIN_TM 56.0`、`MAX_POLY_X 6`；
- **关于引物质量约束的验证边界**：上表中的四个 `_TH` 参数与 `MAX_END_STABILITY`，
  **本版已按两条独立路线复核**：① `scripts/17_dimer_check.py` **直查约束量本身**——
  强制放置读回每对交付引物的 `SELF_ANY_TH` / `SELF_END_TH` / `HAIRPIN_TH` / `COMPL_ANY_TH` /
  `COMPL_END_TH`，对照设计上限 47.0，结果 **21 ok / 3 warn / 0 fail，无越界**（全场最大 45.73）；
  ② 同脚本用自实现的 SantaLucia (1998) 统一最近邻参数（**不经 primer3**）重算 dimer / hairpin ΔG，
  作为物理量参考，并与 primer3 在同盐条件下交叉校验（r = 0.936）。
  详见 §7 表 C4 行与 §14.2；边界（hairpin 未加环熵罚分，故为稳定性上界；
  该 NN 量与 primer3 `HAIRPIN_TH` **不可互相换算**，r = −0.34）见 §14.2。
- 坐标约定（**已由交付数据反验证**）：`产物 = rp + 1 - lp`，其中 `lp`/`rp` 是 primer3 在模板中的 0-based offset。
  注意 `PRIMER_RIGHT` 的 start 是右引物**最右侧（即 5'）碱基**的坐标，不是 3' 端
  （README 原文字描述有误，已更正，见 §9.7；公式本身一直正确）。

### 4.3 特异性择优与计数

1. 对全部候选引物做全基因组匹配（正反链全长 + 3' 端 15-mer），`03b_pick_specific.py` 按
   `score = min(full_off,5)*400 + min(end15_off,60)*8 + penalty + (product/分母)*20` 择优；
2. **权威计数**由 `11_validate_genome_scan.py` 用 numpy base-4 滚动哈希独立重扫得到
   （15-mer 编码 + 逐条字符串复核，按基因组位置计数，含重叠出现），结果写入 `method_D_genomescan.json`；
3. `grep -o` 只报非重叠匹配，在 (CA)n 等区域会少计，仅用于排序。

Ensembl REST `overlap/region` (GRCh38) 取基因体注释，UCSC `ncbiRefSeqCurated` 交叉核对。
24 行全部标注为 `gene-body`。

## 6. 全基因组特异性：能证明什么，不能证明什么

### 6.1 已证实的部分

- 48/48 条引物在全基因组（455 contig / 3.21 Gbp，双链）**精确全长匹配恰好命中 1 次**，即其自身位点；
- 48/48 条引物**全长脱靶 = 0**；`pair_full_off` 全部为 0；
- 该结论在四个文件中一致（TSV・`designed.json`・`method_D_genomescan.json`・`specificity.tsv` 的 `full_hits` 列），
  且由 grep 与 numpy 两种独立实现互证——这是本面板最扎实的一项证据。
- **注**：§1 术语约定 (2) 披露的"同染色体命中不计入异地命中"这一偏低问题**不影响本节的结论**。
  因为全长命中恒为 1（就是目标位点、就在本染色体），故 `全长异地命中 = 1 − 1 = 0`
  与"全基因组无第二处精确匹配"**等价**。该定义问题只影响 15-mer 这类计数远大于 1 的指标。

### 6.2 该结论**不**等价于"无非特异扩增风险"

**这是本报告上一版最严重的表述错误，本版已更正。** 上一版在此处写"没有一条引物存在真实的非特异扩增风险证据"，
这句话与本报告自己列出的数据（下一段）自相矛盾，且方法学上不成立。

理由：PCR 引物**不需要**精确匹配就能延伸。真实的非特异扩增来自部分匹配——3' 端匹配程度、
错配位置与数量、局部 GC 环境、两端组合与产物长度共同决定。**精确 22-mer 唯一性只覆盖了其中一种失效模式。**
对于本项目这样的 GC 富集重复模板，这一区别尤为重要（重复区本身就是错配延伸的高发区）。

### 6.3 近似筛查指标：3' 端 15-mer（**仅筛查，不是特异性证明**）

15-mer 仅 15 nt，在 3.2 Gbp 中必然出现偶然命中。本项目的定位是**快速风险筛查 + 择优排序**，
阈值取"异地命中 > 10"即降级为 `ok_check`。全部 24 行异地命中分布为 1–57，中位数 7。

**该指标不能当作 PCR 特异性证明。** 它不考虑：错配的存在与数量、错配在 3' 端的**具体位置**、
完整引物的 Tm、F/R 能否形成配对、两引物距离与方向、产物长度、局部 GC 环境。

**它也不宜叫"脱靶"。** "脱靶"容易被实验人员读成"这一对引物会产生 N 个 PCR 产物"；
它实际测的只是"该引物 3' 端 15-mer 在**其它染色体**上精确出现了多少次"。
字段的精确数学定义见 **§1 术语约定 (2)**，其中包含一条本版新披露的**系统性偏低**问题

### 6.4 错配容忍的引物配对特异性 — **本次已执行**（原为交付的主要缺口）

真正的引物**配对**特异性验证——容许 mismatch 的 in-silico PCR——已由 `scripts/18_mismatch_pcr.py` 完成，
搜索空间为：

```
F 引物候选结合位点（3' 端种子精确 + 全引物错配预算）
+ R 引物候选结合位点（同上）
+ 方向正确 / 距离合理（100–3000 bp）/ 正负链两条通路
→ 是否存在可扩增的潜在产物
```

**方法**：对每条 contig 做一次滚动 4 进制 k-mer 编码扫描；同一次扫描服务多档种子长度
（长度 S 的窗口编码 c 的前缀 s 位 = `c // 4**(S-s)`，后缀 s 位 = `c % 4**s`），
命中后逐条核验全引物错配数与 3' 端连续精确长度，最后按方向与距离配对。参数做三档敏感性：

| 配置 | 3' 端精确种子 | 全引物错配上限 | 基因组命中位点 | **可扩增脱靶产物** |
|---|---|---|---|---|
| `seed15_mm3`（≈UCSC isPCR 默认） | 15 nt | ≤3 | 83 | **0** |
| `seed12_mm4` | 12 nt | ≤4 | 855 | **0** |
| `seed10_mm6`（最宽松） | 10 nt | ≤6 | 20,626 | **0** |

扫描范围：`data/hg38_oneline/` 25 条主染色体，3.088 Gbp，**全部 24 对（含 4 个 chrX 位点）**。
即在最宽松档下，20,626 个引物结合位点中，**没有任何一对 F/R 位点以正确方向、在可扩增距离内相向排列**。

**内建阳性对照**：每对的 on-target 产物必须被同一套代码召回且坐标吻合——**24/24 通过**
（0 错配、3' 端连续精确 22/22、起止坐标与交付表一致）。

**扫描器本身经过独立校验**（`scripts/19_validate_mismatch.py`，12/12 通过），因为"0 脱靶"只有在能证明
"有脱靶时检得出来"时才有意义：

| 合成对照 | 预期 | 实测 |
|---|---|---|
| 人工插入的精确配对（相距 ~320 bp） | 三档均检出 | ✅ |
| F 引物 5' 半段 2 个错配（3' 15-mer 完好） | 检出，fwd_mm=2、3' 锚定 18 bp | ✅ |
| F 引物 6 个错配（3' 15-mer 完好） | 严格档拒绝、宽松档检出 | ✅ |
| 相距 5 kb | **不**报告 | ✅ |
| 方向错误（F/R 同向） | **不**报告 | ✅ |
| 负链产物通路 | 检出，`strand='-'` | ✅ |
| **spike-in**：把已知脱靶插入真实 chr1 | 在真实背景中唯一检出 | ✅ |

**本节的边界（不可外推的部分）**：

1. **种子必须精确**。扫描允许 5' 侧错配，但要求 3' 端种子逐位精确。真实 mispriming 也可由
   3' 端存在错配的位点引发（效率低得多但不是零），**这类位点未被覆盖**。
2. **参数网格之外未测**。`seed10/mm6` 更宽松的组合（更短种子、更多错配）未扫描。
3. **只扫描 25 条主染色体**（3.088 Gbp），未含 hg38.p14 的 `_fix`/`_alt`/`unplaced` 支架
   （约 190 Mb，约 6%）。原 `method_D` 的口径是 455 contig / 3.209 Gbp。
4. **in-silico ≠ 湿实验**。本方法不建模模板二级结构、聚合酶、缓冲液与退火动力学。

**结论定位**：配对特异性**已从"完全未测"变为"在明确参数网格内已测，未发现可扩增脱靶"**。
这是本次交付中证据强度提升最大的一项；但它仍**不等于**"不存在非特异扩增"，
最终证据仍是参考 DNA（如 NA12878）上的湿实验（§12.7）。

> **给实验方的建议**：§6.3 的 6 条 `ok_check` 行仍建议优先人工确认（那是 3' 短匹配的筛查值，
> 与本节测的是不同维度：前者是"引物单独能贴多广"，后者是"两引物能否成对扩增"）。

### 9.1 `specificity.tsv` 的 3' 15-mer 计数错误 — 已修复

- **现象**：10 条**反向**引物的 `end15_hits` 为 **0**（#1 FMR1、#2 AFF2、#3 chr12、#9 RHOT1、
  #10 FAM193B、#11 PCDH8P1、#13 ZSWIM6、#14 EGR3、#16 PKN2-AS1、#18 ADGRL3），

  引物自身的结合位点保证其 3' 端 15-mer 至少出现 1 次。
- **根因**：`03_check_specificity.py` 的模式文件写入的是 `s[-15:]` 与 `rc(s[-15:])`（正确），
  但查表用了 `seq_r[-15:]`，其中 `seq_r = rc(seq_f)`。
  `rc(seq_f)[-15:]` 等于 `rc(seq_f[:15])`——即 **5' 端 15-mer 的反向互补**，
  **它根本不在 grep 搜索过的模式集合里**，因此查表恒为 0（左引物因第一项有值而不受影响）。
- **修复**：改用 `end_f, end_r = seq_f[-15:], rc(seq_f[-15:])`。
- **验证**（合成基因组端到端，修复前后同输入对比）：

  | 版本 | 左引物 end15_hits | 右引物 end15_hits |
  |---|---|---|
  | 修复前（git HEAD 原版） | 1 | **0** ← 不可能值 |
  | 修复后 | 1 | **1** |

  与交付文件中"右引物恒为 0、左引物从不为 0"的特征完全吻合。
- **影响**：**交付的 TSV 不受影响**——其 `*_end15_off` 列由 `05_build_report.py` 从
  `method_D_genomescan.json` 覆盖写入。受影响的只有 `specificity.tsv` 这个辅助文件本身。

### 9.4 `data_review.md` 中 CCDC9 (#15) 的 walk 复现区间与交付区间不一致 — 脚本已修复

## 12. PCR 与实验验证注意事项（GC 富集重复）

> 以下为**起始建议**，不是固定 SOP。不同聚合酶/缓冲液/模板的最优条件差异很大，
> 建议按条件梯度自行优化，而不是一次性叠加多种添加剂。

1. **聚合酶与缓冲液**：GC 富集模板建议用高保真 GC-buffer 聚合酶（Q5 GC Enhancer、
   Phusion GC Buffer、KAPA2G Robust 等），尤其 chr12 / GIGYF1 / CARM1 这类长 GC 重复位点。
2. **添加剂**：DMSO 3–5% 或 betaine 0.5–1.5 M 常可改善解链；可与 7-deaza-dGTP（3:1）合用。
   建议先做 **DMSO 0 / 2 / 3 / 5% 梯度**，并配合退火温度梯度（见下），而不是一次性全加。
3. **循环策略**：98℃ 变性；退火 = Tm − 3℃ 起步做梯度 / touchdown（如 65→58℃）；
   延伸按产物长度常规设置（均 < 1 kb）。
4. **滑链（stutter）**：GC 富集串联重复在 PCR 与 Sanger 中**易出现** ±1 单元 mixed peak
   （(GC)n 二核苷酸更明显）。定长以主峰 / 峰包中位为准，正反双向测序；
   精确定长优先荧光毛细管电泳（GeneScan）。
5. **拷贝数定标**：本表"预期扩增片段"按 **GRCh38 参考序列中该位点的拷贝数**计算（已独立复核）。
   注意 GRCh38 是单一单倍型，**不代表人群典型等位**——repeat 位点高度多态
   （例如 FMR1 数据库中可见 CGG[17]/[18]/[28]/[37]/[43] 等多种等位）。
   实际样本 allele = 预期产物 ± 拷贝数差 × 单元长（GCC 家族 3 bp、GC 家族 2 bp）。
   含中断位点的单元数存在 ±1–2 的定义敏感性（表 C 已给出精确 / 中断 / 纯度）。
6. **扩展位点（FMR1 / AFF2）— 容量限制必须说清楚**：
   GRCh38 参考序列中为 22 / 21 拷贝。患者扩展等位每 +1 拷贝产物 +3 bp。
   **1 kb 产物的理论上限只有 FMR1 ~114 拷贝、AFF2 ~93 拷贝**：

   | 位点 | 1 kb 上限 | 能否覆盖 55–200 前突变 | 覆盖 200 所需产物 |
   |---|---|---|---|
   | FMR1 | ~114 | **否，只到 114** | ~1.26 kb |
   | AFF2 | ~93 | **否**（致病扩增 >200 完全触不到） | ~1.32 kb |

   即：**当前 1 kb 设计下，AFF2 这一对检测不到 AFF2 的致病扩增**，
   FMR1 只能覆盖前突变的下段。若要覆盖 200 拷贝，需把产物上限放宽到 ~1.26 / ~1.32 kb
   （仍在 2 kb 硬上限内，但长 GC 产物扩增效率需实验验证）；
   > 200 拷贝的全突变按文献改用 MP-PCR / Southern / 长读长测序或 AGG 分布测定。
7. **验证建议**：先以参考 DNA（如 NA12878）确认单一条带与预期长度，再引入已知拷贝数差异的对照；
   建议扩增后测序验证侧翼-重复连接处。本表引物已做全基因组**精确匹配**唯一性筛选（双实现，全长脱靶 0），
   但**尚未做容许错配的配对特异性分析**——建议实验前补做（§6.4），并优先确认 §6.3 的 6 条 `ok_check` 行。
8. **建议的实验优先级**（给样本开发组；依据下方准则，非主观排序）：

   > **本版重排说明**：上一版的排序直接用了表 B 的"异地命中"，而该字段按 §1 术语约定 (2)
   > **系统性偏低**。本版改用修正口径 **`总命中 − 2`**（≈ 除目标位点外的全部 15-mer 精确命中；

## 14. 本轮新增的验证（§6.4、§7 C4 的证据来源）

### 14.1 参考基因组身份校验 — `scripts/20_verify_reference.py`

**为什么需要**：面板的全部坐标与计数都以 hg38 表达，但工作参考由多个文件拼装而成时，
一个静默的染色体级不一致会让所有脱靶计数同时出错而不触发任何失败。
所以参考的来源不足以取信，必须直接与 UCSC 比对。

| 校验 | 结果 |
|---|---|
| R1 25 条染色体长度 vs UCSC hg38 | ✅ 全部一致 |
| R2 随机窗口逐位比对 | ✅ 75 × 10 kb = 750 kb 全一致 |
| R3 24 个位点扩增子区间（含引物结合位） | ✅ 全部一致且与交付坐标吻合 |

**过程中发现的一个真实不一致（已修复）**：本机原有的
`/data1/REF_GENOMES/GCA_000001405.15_GRCh38_no_alt_analysis_set.chr1-chr22.fasta`
在 **chr19 与 chr5 的着丝粒**处是 N，而 UCSC hg38 在该处是真实序列
（经 UCSC REST API 与 Ensembl REST 双向确认为同一序列，两者仅差坐标约定 1 bp）。
即该文件并非 UCSC hg38 的等价物，缺失约 4.6 Mb 真实序列。

**修复方式**：改用 UCSC `hg38.p14.chromFa` 的 25 条主染色体。
其 patch 以 `_fix`/`_alt` 独立序列（共 711 条）附加，**主染色体序列与 hg38 逐位相同**
（已由 R1–R3 验证）。修复后 chr19:26,768,098、chr5 着丝粒均与 UCSC 一致。

> **口径说明**：本参考为 **25 条主染色体 / 3.088 Gbp**，不含约 190 Mb 的
> `_fix`/`_alt`/`unplaced` 支架。原 `method_D` 的口径是 455 contig / 3.209 Gbp（含支架），
> 因此 §6.4 的位点计数与 `method_D` 不可直接相减（见该节 V5a 校验的保守方向）。

### 14.2 dimer / hairpin 的独立复算 — `scripts/17_dimer_check.py`

**为什么需要**：原 C4 只是用**同一个 primer3 引擎**重跑一遍，无法发现阈值设错或参数抄错；
且其输出未随包交付（§7）。本脚本改用**自实现的 SantaLucia (1998) 统一最近邻参数**
（1 M NaCl，T=310.15 K）计算 ΔG，穷举所有反平行排列，并同时给出**不依赖任何热力学模型的**
最长连续互补配对长度与 3' 端锚定长度。

**本版修正（承接 §9.22）**：脚本原先用 45 / 35 / 45 kcal/mol 三个硬编码"镜像阈值"与自算 ΔG
比对。这三个数**既不对应真实的设计约束**，也不在该 NN 模型的标度上，且**无法靠改数字修复**——
实测自算 hairpin ΔG 与 primer3 `HAIRPIN_TH` 的相关系数仅 **r = −0.34**（n=24），
因为 NN 模型只算茎区、不加环熵罚分，且 `min_stem=3` 会找出 primer3 不视为发夹的短茎
（例：#3 的 primer3 `HAIRPIN_TH` = 0，NN 却给 −2.16；#2 AFF2 的 `HAIRPIN_TH` = 37.6，NN 只给 −0.81）。
现改为**直查约束量本身**：用强制放置读回每对引物的 `SELF_ANY_TH` / `SELF_END_TH` / `HAIRPIN_TH`
与 `COMPL_ANY_TH` / `COMPL_END_TH`，直接对照设计上限 47.0（这正是 `02b_design_panel.py` 施加的约束，
无需任何换算）。自算 NN 数值保留为**物理量参考**，不再充当阈值判据。

| 结果 | |
|---|---|
| 24 对判定 | **21 ok / 3 warn / 0 fail**（无 `_TH` 越界） |
| 全场最大 `_TH` | **45.73**（#7 TMEM185A 反向引物发夹），上限 47.0——**贴限通过** |
| 贴限（`HAIRPIN_TH` ≥ 34） | 11 条引物 / 9 对：#2 F 37.6、#5 F 45.4、#7 R 45.7、#8 F 39.3、#11 F 36.0 / R 37.2、#17 F 35.3、#21 F 34.1、#22 R 45.5、#23 F 37.3 / R 36.0 |
| 跨引擎一致性（同盐条件，独立量） | Pearson r = **0.936**，平均 \|Δ\| = 1.71 kcal/mol |
| 3 处 warn | #5 GIGYF1（异源 3' 锚定 5 bp）、#7 TMEM185A（R 自二聚体 5 bp）、#19 ENSG00000290113（异源 5 bp） |

三处 warn 由**不依赖任何阈值**的"3' 端连续互补 ≥5 bp"规则触发，属形式提示而非风险；
它们与 `_TH` 是否贴限无关。**注意这 3 处与 §6.3 的 6 条 `ok_check` 基本不重叠**——
3' 短匹配多的位点并不必然有 dimer 问题，两者是不同维度。

**方法学注意**：本脚本的 hairpin ΔG **只算茎区、未加环熵罚分**，因此是稳定性的上界；
它**不可**与 primer3 的 `HAIRPIN_TH` 互相换算（见上）。

### 14.4 上述三项的校验 — `scripts/19_validate_mismatch.py`

**12 项全部通过，0 项跳过**。核心是合成对照与 spike-in：

- 人工构造的脱靶配对在全部三档被检出；错配预算按预期生效（2 错配全档检出、6 错配仅宽松档检出）；
- 相距 5 kb 与方向错误的构造**不**被报告（假阳性对照）；
- 负链产物通路可检出；
- **spike-in**：把已知脱靶插入真实 chr1，在真实背景位点中**唯一**检出该脱靶，同批 on-target 正确归类；
- V4：24/24 位点在交付坐标处被唯一、精确（0 错配）回收；
- V5a/V5b：与 `method_D` 的跨实现一致性——`seed15` 位点数 ≤ `method_D` 的 3'15mer 命中数（83 ≤ 360），
  且每对的 0 错配位点数恰为 1，**独立复现了全长基因组唯一性**。

# 交付表配套说明 — GC / GCC 重复序列引物面板

本文是 `results/primer_panel_delivery.md` / `.csv` 的配套说明。
交付表本身自包含（引物序列、坐标、Tm、重复特点齐备）；本文补充样本制备组在**使用**这批引物时
需要知道的条件与边界。完整证据链见 `results/final_report.md`。

## 一、Tm 的计算条件（重要）

表中 Tm 由 **primer3 2.3.1** 按 SantaLucia 最近邻模型计算，条件为：

```
单价盐 50 mM ／ Mg²⁺ 1.5 mM ／ 引物 50 nM ／ dNTP 0.6 mM
```

已用 Biopython `Tm_NN` 独立复算交叉验证（同盐条件），两引擎最大偏差 **1.81 ℃**。

> **不要直接与其他文献面板的 Tm 数字比较。** 许多已发表面板的 Tm 是在 1 M Na⁺ 或厂商默认条件
> （如 IDT OligoAnalyzer）下给出的，同一引物可相差 5–10 ℃。本表 48 条引物 Tm 集中在
> **59.4–61.0 ℃**、配对 ΔTm ≤ 1.2 ℃。若贵组缓冲液条件不同，请用实际条件重算后再设退火温度。

## 二、PCR 条件建议（GC 富集重复模板）

以下为**起始建议**，非固定 SOP，请按实际聚合酶/缓冲液做梯度优化。

1. **聚合酶 / 缓冲液**：GC 富集模板建议用带 GC buffer 的高保真酶（Q5 GC Enhancer、
   Phusion GC Buffer、KAPA2G Robust 等），尤其 #3 `chr12`、#5 `GIGYF1`、#4 `CARM1`
   这三个重复区 GC 含量最高的位点（93.8–97.3%）。
2. **添加剂**：DMSO 3–5% 或 betaine 0.5–1.5 M 常可改善解链；建议做 **DMSO 0 / 2 / 3 / 5% 梯度**，
   不要一次性叠加多种添加剂。
3. **循环**：98 ℃ 变性；退火 = Tm − 3 ℃ 起步，做温度梯度或 touchdown（如 65→58 ℃）；
   延伸按产物长度常规设置（全部 < 1 kb）。
4. **滑链（stutter）**：GC 富集串联重复在 PCR 与 Sanger 中**易出现** ±1 单元 mixed peak，
   `(GC)n` 二核苷酸位点（#15–#24）最明显。定长请以主峰/峰包中位为准、正反双向测序；
   需要精确定长时优先用荧光毛细管电泳（GeneScan）。
5. **预期产物 338–990 bp**，均 < 1 kb。

## 三、覆盖范围与已知限制（请与需求方确认）

1. **`(GC)n` 二核苷酸档位无法满足 ≥20 拷贝**。GRCh38 参考基因组中 `(GC)n` 完美串联最长仅
   **14 拷贝**，含中断口径最长 18；把种子阈值降到 12 bp 重扫仍为 0。
   因此 #15–#24 这 10 行是该家族**参考基因组中最长的真实位点（12–14 拷贝）**，
   **不是 20–25 档**。
2. **GCC 家族 `>30` 档只有 1 个真实位点**：#3 `chr12:7,628,695`（32 单元 = 26 精确 + 6 中断），
   已由 UCSC 取原始序列逐单元核验。
3. **7 行属于"最接近"档**（#8–#14，16–19 拷贝），用于在参考基因组无真值的情况下尽量填满 20–25 档。
   真正符合 20–25 档的是 #1、#2、#6、#7；符合 25–30 档的是 #4、#5。
4. **FMR1 / AFF2 的扩增容量限制**（影响临床相关位点的可用性，务必注意）：

   | 位点 | hg38 参考序列拷贝数 | 本面板产物 | 1 kb 产物理论上限 | 能否覆盖 55–200 前突变 |
   |---|---|---|---|---|
   | #1 FMR1 | 22 | 723 bp | ~114 拷贝 | **否，只覆盖下段（55–114）** |
   | #2 AFF2 | 21 | 782 bp | ~93 拷贝 | **否**；>200 的致病扩增完全触不到 |

   若要覆盖 200 拷贝，产物上限需放宽到 ~1.26 kb（FMR1）/ ~1.32 kb（AFF2）。
   >200 拷贝的全突变建议改用 MP-PCR / Southern / 长读长测序。
5. **hg38 是单一单倍型，不代表人群典型等位**。表中"参考等位"是该位点在 GRCh38 参考序列中的
   拷贝数；实际样本等位 = 预期产物 ± 拷贝数差 × 单元长（GCC 家族 3 bp、GC 家族 2 bp）。
   含中断位点的单元数存在 ±1–2 的定义敏感性（表中已给出精确 / 中断 / 纯度）。
6. **如需 ≥20 拷贝 (GC)n 或 25–30 / >30 各档标准品**：建议用本表引物侧翼序列 + 指定拷贝数
   重复区合成 gBlock / 质粒，而不是在参考基因组里硬凑。

## 四、特异性与校验状态

- **全基因组精确唯一性**：48 条引物在 GRCh38（双链）**精确全长匹配各恰好 1 次**（即自身位点），
  全长脱靶 **0**。由 `grep -F` 与 numpy 滚动哈希**两种独立实现**互证。
- **错配容忍的配对特异性**（in-silico PCR，三档参数）：在 3.088 Gbp 上，3' 端种子 15/12/10 nt、
  全引物错配上限 3/4/6 三档下分别命中 83 / 855 / 20,626 个引物结合位点，
  **均未发现可扩增的脱靶产物**；24/24 on-target 阳性对照全部正确召回。
  扫描器本身经 12 项合成对照（含真实染色体 spike-in）校验通过。
- **热力学**：Tm/GC 双引擎复算通过；dimer/hairpin 双重复核——
  ① 直查 primer3 `_TH` 族（设计真正约束的量，上限 47.0）**无越界**，全场最大 45.73；
  ② 独立最近邻实现复算（不经 primer3），跨引擎 r = 0.936。合计 21 ok / 3 warn / 0 fail。
- **数据校验**：16 项方法校验全通过；24 行从头复核（不引用设计代码）全部通过；
  发布门禁 27 项全通过。

**边界**：以上均为 **in-silico** 证据。错配扫描不覆盖"3' 端带错配"的结合位点，也不替代湿实验。
**最终特异性证据仍需在参考 DNA（如 NA12878）上确认单一条带与预期长度。**

## 五、流水线与配套文件

交付表由 `scripts/21_build_delivery.py` 从 `results/primer_design_results.tsv` 生成：

```
results/primer_design_results.tsv  (28 列权威设计表)
        │  21_build_delivery.py   ← 派生引物结合坐标 + 压缩 Repeats 特点
        ▼
results/primer_panel_delivery.md / .csv   ← 交付物
```

| 文件 | 内容 |
|---|---|
| `results/primer_panel_delivery.md` / `.csv` | **交付表**（本文的正文对象） |
| `results/primer_design_results.tsv` | 权威设计表（28 列：档位标签、纯度、逐侧特异性计数、flag 等） |
| `results/final_report.md` | 完整报告（方法、证据分级、问题清单） |
| `results/validation_report.md` / `data_review.md` | 两轮独立校验报告 |
| `results/dimer_check.*` / `mismatch_pcr.*` / `reference_check.json` | 热力学、配对特异性、参考基因组身份校验的产物 |

交付表的两项派生量中，**引物结合坐标**由 `16_release_gate.py`（F9）直接从参考基因组复算核对，
不依赖上游产物。
